Live match roster setup

The full roster overlay (roster.html) needs to know which FACEIT match you're currently in. FACEIT's own "current match" endpoint is blocked for servers hosted on cloud platforms like Render, but works fine from an ordinary home connection - so this one lookup runs on your own PC instead, in a small script, and pushes the result to the server.

Prefer a double-click installer instead of the script below? Download the tray app (Windows, unsigned - SmartScreen will warn on first run, click "More info" → "Run anyway"). Same logic, no Node.js/terminal needed.

1. Save this as a file

Save the content below as live-match-relay.mjs anywhere on your PC.

2. Run it whenever you stream

Needs Node.js installed (you already have this if you've used this project before). Open a terminal in the folder where you saved the file and run:

node live-match-relay.mjs

Leave it running in the background the whole time you're streaming. It only reads your own public match status - Ctrl+C to stop it any time.

3. Add the overlay to OBS/Streamlabs

Size it to your whole stream canvas (e.g. 1920×1080).
